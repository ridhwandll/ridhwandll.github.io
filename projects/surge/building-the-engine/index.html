Surge · Build guide

Building the engine

No submodules and no package manager. Every dependency is vendored with its own CMake list, so a plain clone is all you need. Pick your platform below.

1. Clone 2. Windows 3. Android 4. iOS / macOS 5. Folder structure

Clone the repository

No need for recursive clones, the repository has no git submodules. Vendor code is baked in with a custom CMakeLists.txt for each one.

git clone https://github.com/ridhwandll/Surge_Expired

Windows

Surge builds as a static library, and the Editor and Player link against it. The solution is generated as .slnx.

  • ▸ Visual Studio, recent
  • ▸ C++ Clang (ClangCL) toolset
  • ▸ CMake
  • ▸ Vulkan SDK (from the LunarG website)

  1. Generate the projects

    Run the script from the repository root. It generates build/Surge.slnx.

    Scripts\WindowsGenProjects.bat

  2. Build

    Build in Visual Studio, or from the command line:

    msbuild build/Surge.slnx -p:Configuration=Release

  3. Set the startup project

    Set Editor (not Player) as the startup project. The working directory is always the repository root.

Build the whole solution in Release mode before running the Editor.

Shaders are compiled to SPIR-V with shaderc on Windows and cached in Engine/Assets/Shaders/SPIRV/.

Android

On Android Surge builds as a .so (libSurgePlayer.so, via the Gradle project in android/). One script sets up everything you need to export an .apk or .aab from the Editor.

  1. Run the setup script

    Accept everything when prompted (press Y). Android Studio is optional, you can press N there. That downloads everything you need.

    Scripts\AndroidSetup.bat

  2. Export from the Editor

    Open the Editor's Export panel and export an APK or AAB.

arm64-v8aNDK 27.3minSdk 29c++_static

iOS / macOS

Planned, but I can't work on it because I don't have any Apple devices. Linux and macOS desktop builds are intentionally unsupported for now. The plan is a native Metal rendering backend on iOS and macOS.

Folder structure

Where things live once you have cloned the repository.

Engine/                     Surge static library
  Source/Surge/             Main Engine source; All Systems + ECS
  Source/SurgeReflect/      In-house reflection (enum <-> string, registry)
  Source/SurgeMath/         AABB, Frustum and math helpers
  Assets/Shaders/           One .glsl per program (+ Include/*.glsli)
  Vendor/                   Third-party code with custom CMakeLists.txt
Editor/                     Windows-only editor via Dear ImGui
Player/                     Runtime executable (Windows + Android entry points)
android/                    Gradle project, builds libSurgePlayer.so
Scripts/                    Project generation
